# w_jornal (v3.6) — Мобільний щоденник тренувань (PWA)

**w_jornal** — легкий та швидкий прогресивний вебзастосунок (PWA) для планування, обліку та таймінгу силових і функціональних тренувань. Додаток створений для зручної роботи однією рукою на смартфоні (iOS / Android), працює повністю офлайн і зберігає всі дані локально на пристрої без реєстрації та сторонніх серверів.

🔗 **Робоча версія (GitHub Pages):** https://3khgena-glitch.github.io/w_jornal/

## Основні можливості (v3.6)

### 1. Календар та планування (`План`)
* **Режим «Таблиця» (Матриця на 7 днів):** компактна сітка на тиждень із навігацією по днях, кнопкою швидкого повернення «Сьогодні» та фільтрацією активних тренувань періоду. У клітинках відображаються перша літера назви та фактичний час (`--:--` або тривалість).
* **Картка обраного дня:** під таблицею виводиться детальна картка обраної дати (за замовчуванням — «Сьогодні») зі списком вправ, вагою, повторами та великою кнопкою швидкого старту тренування.
* **Режим «Місяць» (Безперервна стрічка):** вертикальний календар з вибором місяця/року та контрастним кольоровим розділенням періодів навіть при щоденних тренуваннях:
  * *Попередній місяць* — приглушений сіро-сталевий фон;
  * *Обраний місяць* — насичений смарагдово-зелений для виконаних занять;
  * *Наступний місяць* — виразний блакитний колір із роздільною лінією та бейджем 1-го числа.
* **Гнучке закриття тренувань:** заняття можна запустити з таймером або відмітити виконаним заднім числом (`--:--`) із додаванням примітки.

### 2. Шаблони тренувань (`Тренування`)
* Створення, редагування та видалення власних програм тренувань.
* Прив'язка шаблонів до груп м'язів та сортування за ними.
* Додавання вправ із довідника (зокрема кількох підходів однієї вправи з різними параметрами), зміна порядку вправ стрілками, вказання **ваги**, **типу еспандера** та **повторів** (у довільному форматі: `10-5-10`, `5x8` тощо).
* **Управління групами м'язів:** перейменування груп (оновлюється автоматично в усіх вправах і шаблонах) та безпечне видалення з перенесенням вправ у категорію «Загальна».

### 3. Довідник вправ (`Вправи`)
* Готова стартова база вправ (*Минотавр, Ноги, Драбина з гирею, Трастер, Бруси, Дельти, Спина*) + додавання власних.
* Алфавітне сортування (`uk-UA`) та миттєвий пошук за назвою або групою м'язів.
* **Захист історії:** під час завершення тренування зберігається «знімок» назв та груп м'язів вправ, тому подальше редагування чи видалення вправ у довіднику не псує минулі записи.

### 4. Професійні таймери (`Таймер`)
* **Табата:** налаштування часу роботи, відпочинку та кількості циклів (останні налаштування зберігаються автоматично), 5-секундна фаза підготовки (`PREP`), звукові сигнали за 3-2-1 секунду до зміни фази та утримання екрана активним (Wake Lock + аудіо-підтримка для iOS Safari).
* **Фактичний час:** точний фоновий підрахунок часу (працює навіть при згортанні браузера чи блокуванні екрана) з розбивкою на **Розминку**, **Основну частину** та **Заминку**.
* **Таймер відпочинку між підходами:** великий висококонтрастний лічильник із кроком ±5 секунд (під час відліку стає помаранчевим, а за 5 секунд до кінця — червоним зі звуковим сигналом), який не зупиняє загальний таймер тренування.
* **Екран підсумків:** можливість скоригувати час фаз, відредагувати виконані вправи/вагу/повтори та залишити текстову примітку перед збереженням в історію.

### 5. Резервне копіювання та аналітика (`Дані`)
* **Експорт / Імпорт JSON:** повне збереження та відновлення бази даних одним файлом.
* **Експорт для аналізу:** вивантаження історії у форматі `.csv` (UTF-8) або копіювання готового текстового звіту за весь час чи останні 30 днів.
* **Очищення пристрою:** безпечне повне скидання локальної бази даних із підтвердженням.

## Інструкція для нового користувача

### Крок 1. Встановлення на телефон (як окремий додаток)
* **iPhone (Safari):**
  1. Відкрийте посилання `https://3khgena-glitch.github.io/w_jornal/` у браузері **Safari**.
  2. Натисніть кнопку **«Поділитися»** (квадрат зі стрілкою вгору внизу екрана).
  3. Оберіть **«На початковий екран»** (*Add to Home Screen*) → **«Додати»**.
* **Android (Chrome):**
  1. Відкрийте посилання у **Google Chrome**.
  2. Натисніть меню **⋮** у правому верхньому куті → **«Додати на головний екран»** (*Install app*).

### Крок 2. Перший запуск та налаштування бази
1. При першому відкритті програма автоматично завантажить стартовий набір вправ і шаблонів.
2. Перейдіть у вкладку **«Вправи»**, щоб переглянути довідник, відредагувати існуючі рухи або додати нові через кнопку **`+`**.
3. Перейдіть у вкладку **«Тренування»**, щоб налаштувати під себе вагу, еспандери та кількість повторів у шаблонах або створити нове тренування.

### Крок 3. Планування та проведення тренування
1. У вкладці **«План»** (режим *Таблиця* або *Місяць*) натисніть на порожню клітинку потрібного дня або кнопку **`+`**, щоб запланувати тренування.
2. У день тренування натисніть на заплановану клітинку (або скористайтеся карткою дня під таблицею) та оберіть **«Почати тренування»**.
3. У вкладці **«Таймер»** (режим *Фактичний час*) перемикайте етапи: **Розминка → Основна → Заминка**. Між підходами запускайте вбудований **Таймер відпочинку**.
4. Після завершення натисніть **«Завершити тренування»**, за потреби скоригуйте підходи чи додайте примітку (наприклад, самопочуття або робочу вагу) і натисніть **«Зберегти»**.
5. Якщо тренування пройшло без телефона, натисніть на план у календарі та оберіть **«Відмітити ВИКОНАНО (--:--)»**.

### Крок 4. Безпека даних (Резервні копії)
* Усі дані зберігаються виключно в пам'яті вашого браузера (`IndexedDB`). Якщо очистити кеш браузера або видалити вебдодаток, історія зітреться.
* Раз на 1–2 тижні заходьте у вкладку **«Дані»** та натискайте **«Вивантажити дані»**, щоб зберегти резервний `.json` файл на телефон або в хмарне сховище.

## Технології та локальний запуск

* **Стек:** React, TypeScript, Vite, Tailwind CSS
* **Локальна БД:** Dexie.js (IndexedDB, схема `WJornalDB_v7`) + `localStorage`
* **Навігація та іконки:** `react-router-dom`, `lucide-react`
* **Деплой:** GitHub Actions → GitHub Pages (Node.js 20)
